## Integration rules

1. Compare the source HTML and copied assets before editing. Keep the source's markup, text, classes, responsive behavior, plugin initialization, and dependency order intact.
2. Use `asset('assets/...')` for copied local assets in Blade. Use named Laravel routes for implemented pages; previous `.html` URLs for those pages permanently redirect to clean paths. Unimplemented Tourm placeholders may retain demo links.
3. Keep the shared layout/header/footer and overlay boundaries. Reuse `site-nav-items.blade.php` for any navigation change; do not duplicate navigation markup in a page view or redesign copied page bodies during conversion.
4. Preserve Bootstrap and all referenced Tourm plugins. Check actual references before reordering or removing a stylesheet, script, or asset.
5. Do not load the Tailwind Vite entry on this page unless the Bootstrap/Tailwind interaction is deliberately resolved and verified.
6. Treat existing Tourm demo copy, destination/package data, testimonials, contact details, and external form actions as unapproved template placeholders. Do not represent them as verified A&PM information or assume that forms submit to Laravel.

## Frontend checks

Keep the source's responsive behavior and keyboard interactions intact during integration. Verify every converted page in a browser against its source at narrow, medium, and wide viewports after markup or asset changes. Check local asset responses and plugin behavior. The repository has `npm run dev` and `npm run build`; it does not define a frontend test or lint script.
